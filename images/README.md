# 📁 CARPETA DE IMÁGENES - RUMBO CO.

## 📂 Estructura de Carpetas

### `/images/hero/`
**Imagen principal del Hero (sección inicial)**
- Recomendado: `hero-main.jpg` o `hero-main.webp`
- Dimensiones sugeridas: 1920x1080px o mayor
- Formato: JPG, WEBP o PNG
- Debe ser una imagen de destinos de México (playa, pueblos mágicos, naturaleza)

### `/images/destinos/`
**Imágenes para las tarjetas de destinos (grid)**
- `creel.jpg` - Creel, Chihuahua
- `sancristobal.jpg` - San Cristóbal de las Casas
- `parras.jpg` - Parras de la Fuente
- `cancun.jpg` - Cancún
- `mazatlan.jpg` - Mazatlán
- `tulum.jpg` - Tulum

Dimensiones sugeridas: 800x600px o mayor
Formato: JPG, WEBP o PNG

### `/images/modales/`
**Imágenes grandes para los modales/popups**
- `creel-modal.jpg` - Creel, Chihuahua (modal)
- `sancristobal-modal.jpg` - San Cristóbal de las Casas (modal)
- `parras-modal.jpg` - Parras de la Fuente (modal)
- `cancun-modal.jpg` - Cancún (modal)
- `mazatlan-modal.jpg` - Mazatlán (modal)
- `tulum-modal.jpg` - Tulum (modal)

Dimensiones sugeridas: 1200x800px o mayor
Formato: JPG, WEBP o PNG

## 📝 Notas Importantes

- **Nombres de archivos**: Usa nombres en minúsculas y sin espacios (usa guiones o guiones bajos)
- **Optimización**: Comprime las imágenes antes de subirlas para mejor rendimiento
- **Formatos recomendados**: 
  - WEBP (mejor compresión)
  - JPG (compatibilidad universal)
  - PNG (si necesitas transparencia)

## 🔄 Después de agregar las imágenes

Una vez que agregues las imágenes, avísame y actualizaré las rutas en el código HTML para que las use automáticamente.
